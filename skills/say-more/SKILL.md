name: say-more
description: Explain concepts in greater depth through multiple complementary perspectives while staying high-signal. Use when the user asks for a detailed explanation, wants to build understanding, needs different learning approaches, or says "say more."
---

say more.

Start with the clearest core explanation, then deepen understanding through distinct, useful perspectives.

- Adapt depth, vocabulary, and examples to the user.
- Choose only perspectives that add understanding: plain-language intuition, precise mechanism, analogy, example, counterexample, comparison, or practical application.
- Give each explanation a different mental model, context, or implication. Never merely paraphrase the same point.
- Label perspectives clearly. Prefer short sections, bullets, steps, or comparison tables for scanability.
- Define unfamiliar terms plainly and avoid unnecessary jargon.
- Include material caveats and common misconceptions, not trivia.
- Stop when another explanation would add length but not understanding.
